## 🚀 Key Projects

### 🏥 MediQueue: Smart Hospital Queue
Built during the **Rab'Hacks hackathon** to reduce long waiting times in hospitals.
* Virtual tickets generated only during opening hours, capped per service, counter reset daily
* QR code opening a **darija-speaking chatbot** that confirms the patient's place, turn number and estimated wait
* Real-time tracking and appointment management, prototyped in Figma
* 🔗 [Repository](https://github.com/salmajaghoua23/MediQueue)

### 💊 Pharmacy Management App
Medical store management application written in **C**, handling medicines and employees with file-based storage.
* Stack: C
* 🔗 [Repository](https://github.com/salmajaghoua23/project_phar)
